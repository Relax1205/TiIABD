## Запуск

Откройте Практика_7.ipynb, выберите Python из окружения .venv в корне репозитория и выполните Restart Kernel → Run All. Код принимает рабочий каталог корня репозитория или папки №7.

Для переноса окружения установите requirements_cpu.txt. Здесь использованы Python 3.12, PyTorch 2.15.0+cpu и torchvision 0.29.2+cpu; список точных версий сохранён. Инструкция по другим сборкам — [официальная установка PyTorch](https://pytorch.org/get-started/locally/).

MNIST, BloodMNIST и CIFAR-10 скачиваются в practice7_data/; каталог исключён из git. Для предварительной загрузки на Windows можно выполнить из корня репозитория:

    python "Практическая работа №7/_build/download_data.py"

У исходных архивов проверяются контрольные суммы. Архив CIFAR-10 при необходимости загружается с зеркала и принимается только при совпадении с авторским MD5 c58f30108f718f92721af3b95e74349a.

Веса применяются с той же архитектурой и предобработкой. Для CIFAR-10 эти параметры сохранены в practice7_results/cifar_config.json; проверка загрузки есть в блокноте. Итоговые модели взяты после пятой эпохи по условию задания.
