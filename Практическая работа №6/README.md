
# Практическая работа №6

Дицель Н.С., ИКБО-11-23.

- **Практика_6.ipynb** — основная и самостоятельная части, код, выполненные ячейки, графики и выводы.
- **Практика_6_ДицельНС_ИКБО-11-23.pdf** — версия блокнота для просмотра и сдачи.
- **Результаты_практики_6.md** — фактические метрики и разбор ошибок.
- **Ответы_на_вопросы_6.md** — очень краткие ответы по лекции и семинару.
- **practice6_results/** — модели, паспорта, разбиения, таблицы, графики и переходы генераторов.

Исходный файл «Самостоятельная часть №6.ipynb» сохранён как выданная заготовка. Полное решение находится в «Практика_6.ipynb».

Откройте блокнот и выполните **Restart Kernel → Run All**. Рабочим каталогом может быть папка практики или корень репозитория. Архивы Literature.zip и sentiment_dataset.zip должны лежать рядом с блокнотом; чтение и распаковка выполняются автоматически. Временные данные сохраняются в practice6_data/.

Окружение: Python 3.12, PySpark 3.5.3, Java 21. Нужны pandas, numpy, matplotlib, nbformat, nbclient, ipykernel; wordcloud необязателен. На Windows используются Hadoop DLL и winutils из C:\hadoop либо из папки практики №3. Порядок подготовки, обучения и проверки полностью содержится в блокноте.

Служебные скрипты в _build/ позволяют пересобрать блокнот, выполнить его и экспортировать PDF. Для обычного запуска они не требуются.
